## AI-Powered

AI-powered tools that generate presentations from prompts, content, or simple text descriptions.

- [Runable.com](https://runable.com) - AI-powered platform for generating presentations, websites, and more. Full-stack solution for designers and developers.
- [Gamma](https://gamma.app) - A new medium for presenting ideas, powered by AI. Create presentations, websites, and documents in seconds without coding or design skills.
- [Tome](https://tome.app) - AI-powered storytelling format with beautiful, dynamic layouts. Perfect for narrative-driven presentations.
- [Beautiful.ai](https://www.beautiful.ai) - Generative AI presentation software for teams. Smart Slides automatically adjust layouts and apply brand guidelines.
- [Decktopus](https://www.decktopus.com) - AI presentation generator with auto-adjusted layouts. Create professional decks in minutes with voice recording and forms.
- [Slides AI](https://www.slidesai.io) - AI-powered Google Slides add-on. Generate presentation slides from any text in seconds. Supports 100+ languages.
- [GenPPT](https://genppt.com) - Create complete slide decks instantly from text prompts. Generates up to 10 slides at a time with chat-based editing.
- [SlidesGo AI](https://slidesgo.com/ai/presentation-maker) - Free AI presentation maker. Convert topics into stunning presentations with 100+ professional templates.
- [Presentations.AI](https://www.presentations.ai) - Create PPTs, infographics, charts, timelines, project plans, and product roadmaps with AI.
- [Plus AI](https://www.plusai.com) - AI add-in for PowerPoint and Google Slides. Works within your existing tools for seamless AI-assisted editing.
- [Simplified](https://simplified.com) - All-in-one AI content creation platform with presentation maker. Includes design, video, and copywriting tools.
- [Designs.ai](https://designs.ai) - AI-powered creative suite with presentation maker, logo creator, and video editor.
- [Slideoo](https://slideoo.ai) - AI presentation maker that transforms documents and ideas into slides. Real-time collaboration and export to multiple formats.
- [PopAI](https://www.popai.pro) - AI assistant for creating presentations with smart content suggestions and visual enhancements.
- [Kroma.ai](https://kroma.ai) - AI-powered presentation tool focused on sales and marketing decks. Automatic design suggestions and content optimization.

## AI-Powered (Enterprise & Advanced)

Professional-grade AI tools for large teams with compliance, security, and customization requirements.

- [Prezent](https://www.prezent.ai) - Enterprise AI presentation software with contextual intelligence. Features 100% brand compliance and 35,000+ templates.
- [Storydoc](https://storydoc.com) - AI-powered interactive presentations for sales, marketing, and investor pitches. Real-time analytics and engagement tracking.
- [Prezi AI](https://prezi.com) - Visual storytelling software with AI enhancements. Non-linear, conversational presentations with dynamic zoom features.
- [Curipod](https://curipod.com) - AI-powered interactive presentations designed for educators and trainers. Features real-time engagement tools.

## Web-Based & Collaborative

Cloud-based tools with real-time collaboration, easy sharing, and cross-platform access.

- [Pitch](https://pitch.com) - Collaborative presentation software for modern teams. Real-time editing, commenting, and version control with Slack integration.
- [Canva](https://www.canva.com) - Free design tool with thousands of presentation templates. Magic Design AI for auto-generated layouts. 2M+ assets.
- [Google Slides](https://www.google.com/slides/about/) - Free online presentations with seamless real-time collaboration. Integrates with Google Drive, Docs, and Sheets.
- [Visme](https://www.visme.co) - Drag-and-drop editor with 15,000+ templates, animations, and data visualizations. Brand Wizard for consistent branding.
- [Slidebean](https://www.slidebean.com) - AI-assisted presentation tool for pitch decks. Combines professional templates with collaborative editing.
- [Microsoft PowerPoint Online](https://www.microsoft.com/en-us/microsoft-365/powerpoint) - Cloud-based PowerPoint with real-time collaboration, Designer AI, and Copilot integration.
- [Zoho Show](https://www.zoho.com/show/) - Online presentation software with real-time collaboration. Part of Zoho's productivity suite.
- [Slides](https://slides.com) - Web-based presentation editor built on Reveal.js. Combines code flexibility with visual editing interface.
- [Swipe](https://www.swipe.to) - Mobile-first presentation platform. Create and present from any device with touch-optimized controls.
- [Emaze](https://www.emaze.com) - Cloud-based presentation software with 3D templates and automatic design. Video presentations and analytics included.
- [Genially](https://genial.ly) - Create interactive presentations, infographics, and gamified content. Rich animation and interactivity options.

## Developer & Markdown-Based

Perfect for developers who prefer writing code and using version control. These tools integrate with Git/GitHub workflows.

- [Slidev](https://sli.dev) - Presentation slides for developers. Write in Markdown, Vue, and HTML. Built with Vue.js and Vite. MIT licensed.
- [Reveal.js](https://revealjs.com) - The HTML Presentation Framework. Create interactive, web-based presentations with HTML/CSS/JS. Supports nested slides and plugins.
- [Marp](https://marp.app) - Markdown Presentation Ecosystem. Convert Markdown into HTML, PDF, and PowerPoint. VS Code extension available.
- [Remark.js](https://remarkjs.com) - Create Markdown presentations on Linux and other platforms. Simple, powerful, and highly customizable with plugins.
- [MDX Deck](https://mdx-deck.jxnblk.com) - React + Markdown presentation framework. Build presentations using MDX syntax with full React component support.
- [Spectacle](https://formidable.com/open-source/spectacle/) - React-based presentation library. Build presentations with JSX and React components.
- [Fusuma](https://hiroppy.github.io/fusuma/) - Markdown-based presentation tool with live reload. Supports WebSlides and PDF export.
- [Deckset](https://www.deckset.com) - Mac & iOS app. Write presentations in Markdown with beautiful themes. Perfect for Apple ecosystem users.
- [Cleaver](https://jdan.github.io/cleaver/) - 30-second slideshows for hackers. Generate presentations from Markdown files with simple YAML configuration.
- [Hacker Slides](https://github.com/msoedov/hacker-slides) - Presentation tool for developers. Write in Markdown, present from browser, and store in GitHub.
- [Pandoc](https://pandoc.org) - Universal document converter. Convert Markdown to many presentation formats (reveal.js, PowerPoint, Beamer, etc.).
- [Backslide](https://github.com/sinedied/backslide) - CLI tool for creating HTML5 presentations from Markdown. Lightweight and developer-friendly.
- [Sli.do](https://www.slido.com) - Q&A and polling platform that integrates with presentations. Perfect for developer conferences and tech talks.

## Visual & Interactive

Tools emphasizing creativity, visual appeal, and interactive audience engagement.

- [Prezi](https://prezi.com) - Non-linear, visual storytelling software with zoom-based navigation. Cinematic and engaging presentation style.
- [Ludus](https://ludus.one) - Limitless creativity for slides. Advanced visual editing with animations, custom layouts, and interactive elements.
- [Haiku Deck](https://www.haikudeck.com) - Beautiful, visual presentations with professionally designed templates. AI image search integration.
- [Powtoon](https://www.powtoon.com) - Video-based presentation creator. Combine slides, animations, and video clips for dynamic content.
- [Vyond](https://www.vyond.com) - Animated video presentation maker. Create professional animated presentations with customizable characters and scenes.
- [Animaker](https://www.animaker.com) - DIY video animation software. Create animated presentations with drag-and-drop interface and 1000+ templates.
- [Vevox](https://www.vevox.com) - Interactive presentation platform with real-time audience engagement tools, polling, and Q&A.
- [Pear Deck](https://www.peardeck.com) - Interactive presentation tool for classroom and training settings. Real-time student responses and engagement.
- [Mentimeter](https://www.mentimeter.com) - Polling and interactive presentation tool. Engage audiences with real-time Q&A, polls, and quizzes.
- [Kahoot!](https://kahoot.com) - Gamified quiz and interactive presentation platform. Perfect for educational and training presentations.
- [Nearpod](https://nearpod.com) - Interactive lesson and presentation platform. Includes VR field trips, 3D objects, and gamification.
- [AhaSlides](https://ahaslides.com) - Interactive presentation software with live polls, quizzes, and word clouds. Great for hybrid events.
- [Poll Everywhere](https://www.polleverywhere.com) - Live polling and Q&A for presentations. Real-time audience response system with SMS and web voting.
- [Wooclap](https://www.wooclap.com) - Interactive presentation platform with 18+ question types. Real-time feedback and engagement analytics.

## Data Visualization & Analytics

Specialized tools for data-driven presentations, charts, and business intelligence.

- [think-cell](https://www.think-cell.com) - Add-in for PowerPoint. Automated creation of advanced charts (Gantt, waterfall, Mekko). Real-time Excel integration.
- [Infogram](https://infogram.com) - Create interactive infographics, charts, and visualizations. Rich data visualization library and real-time collaboration.
- [Datawrapper](https://www.datawrapper.de) - Easy chart and map creation. Perfect for data journalists and analysts. Publish embeddable visualizations.
- [Flourish](https://flourish.studio) - Beautiful data visualizations and interactive charts. No coding required. Templates for storytelling with data.
- [Tableau Public](https://public.tableau.com) - Free data visualization platform. Create interactive dashboards and embed them in presentations.
- [Power BI](https://powerbi.microsoft.com) - Microsoft's business analytics service. Create interactive reports and dashboards for data-driven presentations.
- [Looker Studio](https://lookerstudio.google.com) - Google's free data visualization tool. Turn data into informative dashboards and reports.
- [ChartBlocks](https://www.chartblocks.com) - Simple chart creation tool. Integrates data from multiple sources for real-time updating charts.
- [RAWGraphs](https://www.rawgraphs.io) - Open-source data visualization framework. Create custom vector-based visualizations from spreadsheets.
- [Plotly](https://plotly.com) - Interactive graphing library. Create publication-quality graphs and dashboards with Python, R, or JavaScript.
- [Rollstack](https://www.rollstack.com/) - Automatically creates and updates presentations and documents from live data sources. Syncs charts and metrics from BI tools into Google Slides and PowerPoint.

## Specialized & Niche

- [Keynote](https://www.apple.com/keynote/) - Apple's premium presentation software. Exclusive to macOS/iOS. Elegant design and powerful animation capabilities.
- [LibreOffice Impress](https://www.libreoffice.org) - Open-source presentation software (free alternative to PowerPoint). Supports multiple formats.
- [Apache OpenOffice Impress](https://www.openoffice.org/product/impress.html) - Another free, open-source presentation tool with broad format support.
- [Beamer](https://www.ctan.org/pkg/beamer) - LaTeX document class for creating presentations. Perfect for academic and scientific presentations with complex formulas.
- [Pitch Deck](https://pitchdeck.com) - Specialized tool for startup pitch decks. Templates and guidance from successful fundraising decks.
- [Slidedog](https://slidedog.com) - Multimedia presentation tool. Combine PowerPoint, PDFs, videos, and web pages in one seamless presentation.
- [mmhmm](https://www.mmhmm.app) - Virtual camera app for video presentations. Add slides, effects, and dynamic layouts to video calls.
- [Obsidian](https://obsidian.md) - Note-taking app with markdown-based presentation plugin support. Great for knowledge-driven presentations.
- [Notion](https://www.notion.so) - All-in-one workspace with presentation capabilities. Create slide decks from your notes and databases.
- [Coda](https://coda.io) - Doc-based presentation tool. Combine documents, spreadsheets, and presentations in one platform.
- [OmniGraffle](https://www.omnigroup.com/omnigraffle/) - Diagramming tool that can be extended for presentation creation. Excellent for technical presentations.
- [Miro](https://miro.com) - Online collaborative whiteboard with presentation mode. Perfect for workshops and brainstorming sessions.
- [FigJam](https://www.figma.com/figjam/) - Figma's whiteboard tool with presentation capabilities. Great for design teams and collaborative sessions.

## Open Source

- [Impress.js](https://impress.js.org) - Presentation framework built on modern web technologies. HTML/CSS/JavaScript based.
- [Shower](https://shwr.me) - Simple HTML presentation engine. Lightweight and easy to customize.
- [GitPitch](https://gitpitch.com) - Create presentations from Markdown in Git repositories. Version control for presentations.
- [PPTX.js](https://github.com/meshesha/PPTXjs) - JavaScript library for rendering PowerPoint files in browsers. No server-side dependencies.
- [Big](https://github.com/tmcw/big) - Presentations for busy messy hackers. Simple HTML-based slides with minimal configuration.
- [Bespoke.js](https://github.com/bespokejs/bespoke) - DIY presentation micro-framework. Build custom presentation experiences with plugins.
- [WebSlides](https://webslides.tv) - Create beautiful HTML presentations. 120+ slides ready to use with minimal markup.
- [Sent](https://tools.suckless.org/sent/) - Minimalist presentation tool for X11. Lightweight and Unix-philosophy inspired.
- [Landslide](https://github.com/adamzap/landslide) - Generate HTML5 slideshows from Markdown, ReST, or Textile. Python-based with themes.
- [Hovercraft](https://github.com/regebro/hovercraft) - Create impress.js presentations from reStructuredText. Python-based with 3D effects.
- [Patat](https://github.com/jaspervdj/patat) - Terminal-based presentation tool. Present Markdown slides directly in your terminal.
