## На базе ИИ

Инструменты на базе ИИ, которые создают презентации из подсказок, контента или простых текстовых описаний.

- [Runable.com](https://runable.com) - Платформа на базе ИИ для создания презентаций, веб-сайтов и многого другого. Полноценное решение для дизайнеров и разработчиков.
- [Gamma](https://gamma.app) - Новый формат представления идей, основанный на ИИ. Создавайте презентации, веб-сайты и документы за считанные секунды без навыков программирования или дизайна.
- [Tome](https://tome.app) - Формат повествования на базе ИИ с красивыми, динамическими макетами. Идеально подходит для презентаций, ориентированных на рассказ.
- [Beautiful.ai](https://www.beautiful.ai) - Программное обеспечение для создания презентаций с генеративным ИИ для команд. Умные слайды автоматически настраивают макеты и применяют брендовые руководства.
- [Decktopus](https://www.decktopus.com) - Генератор презентаций на базе ИИ с автоматической настройкой макетов. Создавайте профессиональные презентации за считанные минуты с голосовой записью и формами.
- [Slides AI](https://www.slidesai.io) - Дополнение для Google Slides на базе ИИ. Создавайте слайды презентаций из любого текста за считанные секунды. Поддерживает более 100 языков.
- [GenPPT](https://genppt.com) - Создавайте полные презентации мгновенно из текстовых подсказок. Генерирует до 10 слайдов за раз с возможностью редактирования в чате.
- [SlidesGo AI](https://slidesgo.com/ai/presentation-maker) - Бесплатный инструмент для создания презентаций на базе ИИ. Превращайте темы в потрясающие презентации с использованием более 100 профессиональных шаблонов.
- [Presentations.AI](https://www.presentations.ai) - Создавайте PPT, инфографику, диаграммы, временные шкалы, планы проектов и дорожные карты продуктов с помощью ИИ.
- [Plus AI](https://www.plusai.com) - Дополнение на базе ИИ для PowerPoint и Google Slides. Работает в ваших существующих инструментах для бесшовного редактирования с помощью ИИ.
- [Simplified](https://simplified.com) - Универсальная платформа для создания контента на базе ИИ с инструментом для создания презентаций. Включает инструменты для дизайна, видео и копирайтинга.
- [Designs.ai](https://designs.ai) - Креативный набор инструментов на базе ИИ с возможностью создания презентаций, логотипов и редактирования видео.
- [Slideoo](https://slideoo.ai) - Инструмент для создания презентаций на базе ИИ, который преобразует документы и идеи в слайды. Совместная работа в реальном времени и экспорт в различные форматы.
- [PopAI](https://www.popai.pro) - ИИ-ассистент для создания презентаций с умными предложениями контента и визуальными улучшениями.
- [Kroma.ai](https://kroma.ai) - Инструмент для создания презентаций на базе ИИ, ориентированный на продажи и маркетинговые презентации. Автоматические предложения по дизайну и оптимизация контента.

## На базе ИИ (для предприятий и продвинутых пользователей)

Профессиональные инструменты на базе ИИ для больших команд с требованиями к соответствию, безопасности и настройке.

- [Prezent](https://www.prezent.ai) - Программное обеспечение для создания презентаций на базе ИИ для предприятий с контекстным интеллектом. Обеспечивает 100% соответствие бренду и более 35 000 шаблонов.
- [Storydoc](https://storydoc.com) - Интерактивные презентации с поддержкой ИИ для продаж, маркетинга и презентаций для инвесторов. Аналитика в реальном времени и отслеживание вовлеченности.
- [Prezi AI](https://prezi.com) - Программное обеспечение для визуального сторителлинга с улучшениями на основе ИИ. Нелинейные, диалоговые презентации с функциями динамического масштабирования.
- [Curipod](https://curipod.com) - Интерактивные презентации с поддержкой ИИ, разработанные для преподавателей и тренеров. Инструменты для вовлечения в реальном времени.

Облачные инструменты с возможностью совместной работы в реальном времени, простым обменом и доступом с разных платформ.

- [Pitch](https://pitch.com) - Программное обеспечение для совместной работы над презентациями для современных команд. Редактирование в реальном времени, комментирование и контроль версий с интеграцией Slack.
- [Canva](https://www.canva.com) - Бесплатный инструмент для дизайна с тысячами шаблонов презентаций. Magic Design AI для автоматической генерации макетов. Более 2 миллионов ресурсов.
- [Google Slides](https://www.google.com/slides/about/) - Бесплатные онлайн-презентации с бесшовной совместной работой в реальном времени. Интеграция с Google Drive, Docs и Sheets.
- [Visme](https://www.visme.co) - Редактор с функцией перетаскивания, более 15 000 шаблонов, анимаций и визуализаций данных. Brand Wizard для обеспечения единого брендинга.
- [Slidebean](https://www.slidebean.com) - Инструмент для создания презентаций с поддержкой ИИ для питч-деков. Сочетает профессиональные шаблоны с возможностью совместного редактирования.
- [Microsoft PowerPoint Online](https://www.microsoft.com/en-us/microsoft-365/powerpoint) - Облачный PowerPoint с совместной работой в реальном времени, Designer AI и интеграцией Copilot.
- [Zoho Show](https://www.zoho.com/show/) - Онлайн-программное обеспечение для презентаций с совместной работой в реальном времени. Часть пакета продуктивности Zoho.
- [Slides](https://slides.com) - Веб-редактор презентаций, построенный на Reveal.js. Сочетает гибкость кода с визуальным интерфейсом редактирования.
- [Slidesfly](https://slidesfly.com) - Публикуйте готовые презентации HTML, Reveal.js, Slidev или Marp из CLI или Agent Skill по стабильным ссылкам для общего доступа.
- [Swipe](https://www.swipe.to) - Платформа для презентаций, ориентированная на мобильные устройства. Создавайте и демонстрируйте с любого устройства с оптимизированным управлением касанием.
- [Emaze](https://www.emaze.com) - Облачное программное обеспечение для презентаций с 3D-шаблонами и автоматическим дизайном. Включает видеопрезентации и аналитику.
- [Genially](https://genial.ly) - Создавайте интерактивные презентации, инфографику и геймифицированный контент. Богатые возможности анимации и интерактивности.

## Для разработчиков и на основе Markdown

Идеально для разработчиков, которые предпочитают писать код и использовать контроль версий. Эти инструменты интегрируются с рабочими процессами Git/GitHub.

- [Slidev](https://sli.dev) - Слайды для разработчиков. Пишите на Markdown, Vue и HTML. Построено на Vue.js и Vite. Лицензия MIT.
- [Reveal.js](https://revealjs.com) - HTML-фреймворк для презентаций. Создавайте интерактивные веб-презентации с использованием HTML/CSS/JS. Поддерживает вложенные слайды и плагины.
- [Marp](https://marp.app) - Экосистема презентаций на основе Markdown. Конвертируйте Markdown в HTML, PDF и PowerPoint. Доступно расширение для VS Code.
- [Remark.js](https://remarkjs.com) - Создавайте презентации в формате Markdown на Linux и других платформах. Простой, мощный и высоко настраиваемый с помощью плагинов.
- [MDX Deck](https://mdx-deck.jxnblk.com) - Фреймворк для презентаций на основе React + Markdown. Создавайте презентации с использованием синтаксиса MDX с полной поддержкой компонентов React.
- [Spectacle](https://formidable.com/open-source/spectacle/) - Библиотека для презентаций на основе React. Создавайте презентации с использованием JSX и компонентов React.
- [Fusuma](https://hiroppy.github.io/fusuma/) - Инструмент для создания презентаций на основе Markdown с функцией живой перезагрузки. Поддерживает WebSlides и экспорт в PDF.
- [Deckset](https://www.deckset.com) - Приложение для Mac и iOS. Создавайте презентации в формате Markdown с красивыми темами. Идеально подходит для пользователей экосистемы Apple.
- [Cleaver](https://jdan.github.io/cleaver/) - Слайды за 30 секунд для разработчиков. Генерируйте презентации из файлов Markdown с простой конфигурацией YAML.
- [Hacker Slides](https://github.com/msoedov/hacker-slides) - Инструмент для презентаций для разработчиков. Пишите в Markdown, показывайте из браузера и храните на GitHub.
- [Pandoc](https://pandoc.org) - Универсальный конвертер документов. Конвертируйте Markdown в различные форматы презентаций (reveal.js, PowerPoint, Beamer и др.).
- [Backslide](https://github.com/sinedied/backslide) - Инструмент командной строки для создания HTML5-презентаций из Markdown. Легковесный и удобный для разработчиков.
- [Sli.do](https://www.slido.com) - Платформа для вопросов и ответов, а также опросов, интегрируемая с презентациями. Идеально подходит для конференций разработчиков и технических докладов.

- [Haiku Deck](https://www.haikudeck.com) - Красивые визуальные презентации с профессионально разработанными шаблонами. Интеграция с AI-поиском изображений.
- [Powtoon](https://www.powtoon.com) - Создатель презентаций на основе видео. Комбинируйте слайды, анимации и видеоклипы для создания динамичного контента.
- [Vyond](https://www.vyond.com) - Создатель анимационных видеопрезентаций. Создавайте профессиональные анимационные презентации с настраиваемыми персонажами и сценами.
- [Animaker](https://www.animaker.com) - Программное обеспечение для самостоятельного создания анимации. Создавайте анимационные презентации с помощью интерфейса drag-and-drop и более 1000 шаблонов.
- [Vevox](https://www.vevox.com) - Интерактивная платформа для презентаций с инструментами для взаимодействия с аудиторией в реальном времени, опросами и вопросами-ответами.
- [Pear Deck](https://www.peardeck.com) - Интерактивный инструмент для презентаций в классах и на тренингах. Реакции студентов и вовлеченность в реальном времени.
- [Mentimeter](https://www.mentimeter.com) - Инструмент для опросов и интерактивных презентаций. Вовлекайте аудиторию с помощью вопросов-ответов, опросов и викторин в реальном времени.
- [Kahoot!](https://kahoot.com) - Платформа для геймифицированных викторин и интерактивных презентаций. Идеально подходит для образовательных и обучающих презентаций.
- [Nearpod](https://nearpod.com) - Платформа для интерактивных уроков и презентаций. Включает виртуальные экскурсии, 3D-объекты и элементы геймификации.
- [AhaSlides](https://ahaslides.com) - Программное обеспечение для интерактивных презентаций с живыми опросами, викторинами и облаками слов. Отлично подходит для гибридных мероприятий.
- [Poll Everywhere](https://www.polleverywhere.com) - Живые опросы и вопросы-ответы для презентаций. Система мгновенного отклика аудитории с голосованием через SMS и веб.
- [Wooclap](https://www.wooclap.com) - Платформа для интерактивных презентаций с более чем 18 типами вопросов. Аналитика вовлеченности и обратной связи в реальном времени.

## Визуализация данных и аналитика

Специализированные инструменты для презентаций, основанных на данных, диаграмм и бизнес-аналитики.

- [think-cell](https://www.think-cell.com) - Дополнение для PowerPoint. Автоматизированное создание сложных диаграмм (Ганта, водопад, Мекко). Интеграция с Excel в реальном времени.
- [Infogram](https://infogram.com) - Создание интерактивных инфографик, диаграмм и визуализаций. Богатая библиотека визуализации данных и совместная работа в реальном времени.
- [Datawrapper](https://www.datawrapper.de) - Простое создание диаграмм и карт. Идеально для журналистов и аналитиков данных. Публикация визуализаций для встраивания.
- [Flourish](https://flourish.studio) - Красивые визуализации данных и интерактивные диаграммы. Не требуется программирование. Шаблоны для рассказа историй с помощью данных.
- [Tableau Public](https://public.tableau.com) - Бесплатная платформа для визуализации данных. Создавайте интерактивные панели и встраивайте их в презентации.
- [Power BI](https://powerbi.microsoft.com) - Сервис бизнес-аналитики от Microsoft. Создавайте интерактивные отчеты и панели для презентаций, основанных на данных.
- [Looker Studio](https://lookerstudio.google.com) - Бесплатный инструмент визуализации данных от Google. Превращайте данные в информативные панели и отчеты.
- [ChartBlocks](https://www.chartblocks.com) - Простой инструмент для создания диаграмм. Интегрирует данные из нескольких источников для обновления диаграмм в реальном времени.
- [RAWGraphs](https://www.rawgraphs.io) - Открытая платформа для визуализации данных. Создавайте настраиваемые векторные визуализации из таблиц.
- [Plotly](https://plotly.com) - Библиотека для интерактивной графики. Создавайте графики и панели качества публикации с помощью Python, R или JavaScript.

## Специализированные и нишевые

- [Keynote](https://www.apple.com/keynote/) - Премиальное программное обеспечение для презентаций от Apple. Эксклюзивно для macOS/iOS. Элегантный дизайн и мощные возможности анимации.
- [LibreOffice Impress](https://www.libreoffice.org) - Программное обеспечение для презентаций с открытым исходным кодом (бесплатная альтернатива PowerPoint). Поддерживает множество форматов.
- [Apache OpenOffice Impress](https://www.openoffice.org/product/impress.html) - Еще один бесплатный инструмент для презентаций с открытым исходным кодом и широкой поддержкой форматов.
- [Beamer](https://www.ctan.org/pkg/beamer) - Класс документов LaTeX для создания презентаций. Идеально подходит для академических и научных презентаций со сложными формулами.
- [Pitch Deck](https://pitchdeck.com) - Специализированный инструмент для создания презентаций стартапов. Шаблоны и рекомендации из успешных презентаций для привлечения инвестиций.
- [Slidedog](https://slidedog.com) - Инструмент для мультимедийных презентаций. Объединяйте PowerPoint, PDF, видео и веб-страницы в одной презентации.
- [mmhmm](https://www.mmhmm.app) - Приложение виртуальной камеры для видеопрезентаций. Добавляйте слайды, эффекты и динамические макеты в видеозвонки.
- [Obsidian](https://obsidian.md) - Приложение для заметок с поддержкой плагинов для презентаций на основе Markdown. Отлично подходит для презентаций, основанных на знаниях.
- [Notion](https://www.notion.so) - Универсальное рабочее пространство с возможностями для презентаций. Создавайте слайды из своих заметок и баз данных.
- [Coda](https://coda.io) - Инструмент для презентаций на основе документов. Объединяет документы, таблицы и презентации на одной платформе.
- [OmniGraffle](https://www.omnigroup.com/omnigraffle/) - Инструмент для создания диаграмм, который можно использовать для создания презентаций. Отлично подходит для технических презентаций.
- [Miro](https://miro.com) - Онлайн-доска для совместной работы с режимом презентации. Идеально для воркшопов и мозговых штурмов.
- [FigJam](https://www.figma.com/figjam/) - Инструмент для белой доски от Figma с возможностями для презентаций. Отлично подходит для дизайнерских команд и совместных сессий.

- [Shower](https://shwr.me) - Простой HTML-движок для презентаций. Легкий и легко настраиваемый.
- [GitPitch](https://gitpitch.com) - Создавайте презентации из Markdown в Git-репозиториях. Контроль версий для презентаций.
- [PPTX.js](https://github.com/meshesha/PPTXjs) - Библиотека JavaScript для рендеринга файлов PowerPoint в браузерах. Без серверных зависимостей.
- [Big](https://github.com/tmcw/big) - Презентации для занятых и неорганизованных разработчиков. Простые слайды на HTML с минимальной настройкой.
- [Bespoke.js](https://github.com/bespokejs/bespoke) - Микрофреймворк для создания презентаций своими руками. Создавайте индивидуальные презентации с помощью плагинов.
- [WebSlides](https://webslides.tv) - Создавайте красивые HTML-презентации. Более 120 готовых слайдов с минимальной разметкой.
- [Sent](https://tools.suckless.org/sent/) - Минималистичный инструмент для презентаций на X11. Легкий и вдохновленный философией Unix.
- [Landslide](https://github.com/adamzap/landslide) - Генерация HTML5-презентаций из Markdown, ReST или Textile. Основан на Python с поддержкой тем.
- [Hovercraft](https://github.com/regebro/hovercraft) - Создавайте презентации impress.js из reStructuredText. Основан на Python с 3D-эффектами.
- [Patat](https://github.com/jaspervdj/patat) - Инструмент для презентаций в терминале. Показывайте слайды в формате Markdown прямо в вашем терминале.
