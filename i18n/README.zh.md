## AI 驱动

由 AI 驱动的工具，可根据提示、内容或简单的文本描述生成演示文稿。

- [Runable.com](https://runable.com) - AI 驱动的平台，用于生成演示文稿、网站等。为设计师和开发者提供的全栈解决方案。
- [Gamma](https://gamma.app) - 由 AI 驱动的全新创意展示媒介。无需编码或设计技能，几秒钟内即可创建演示文稿、网站和文档。
- [Tome](https://tome.app) - AI 驱动的叙事格式，具有美观、动态的布局。非常适合以叙事为主导的演示文稿。
- [Beautiful.ai](https://www.beautiful.ai) - 为团队设计的生成式 AI 演示软件。智能幻灯片会自动调整布局并应用品牌指南。
- [Decktopus](https://www.decktopus.com) - AI 演示生成器，自动调整布局。通过语音录制和表单功能，几分钟内即可创建专业演示文稿。
- [Slides AI](https://www.slidesai.io) - AI 驱动的 Google Slides 插件。几秒钟内从任何文本生成演示幻灯片。支持 100 多种语言。
- [GenPPT](https://genppt.com) - 通过文本提示即时创建完整的幻灯片组。一次最多生成 10 张幻灯片，并支持基于聊天的编辑。
- [SlidesGo AI](https://slidesgo.com/ai/presentation-maker) - 免费的 AI 演示文稿制作工具。将主题转换为令人惊叹的演示文稿，提供 100 多种专业模板。
- [Presentations.AI](https://www.presentations.ai) - 使用 AI 创建 PPT、信息图表、图表、时间轴、项目计划和产品路线图。
- [Plus AI](https://www.plusai.com) - 适用于 PowerPoint 和 Google Slides 的 AI 插件。在现有工具中无缝进行 AI 辅助编辑。
- [Simplified](https://simplified.com) - 一体化 AI 内容创作平台，包含演示文稿制作工具。还包括设计、视频和文案工具。
- [Designs.ai](https://designs.ai) - AI 驱动的创意套件，包含演示文稿制作工具、标志创建器和视频编辑器。
- [Slideoo](https://slideoo.ai) - AI 演示文稿制作工具，将文档和想法转化为幻灯片。支持实时协作并导出为多种格式。
- [PopAI](https://www.popai.pro) - 用于创建演示文稿的 AI 助手，提供智能内容建议和视觉增强功能。
- [Kroma.ai](https://kroma.ai) - 专注于销售和营销演示文稿的 AI 驱动工具。提供自动设计建议和内容优化。

## AI 驱动（企业与高级版）

面向大型团队的专业级 AI 工具，满足合规性、安全性和定制化需求。

- [Prezent](https://www.prezent.ai) - 企业级 AI 演示软件，具有上下文智能功能。提供 100% 品牌合规性和 35,000 多种模板。
- [Storydoc](https://storydoc.com) - 由 AI 驱动的互动演示文稿，适用于销售、市场营销和投资者提案。提供实时分析和参与度跟踪。
- [Prezi AI](https://prezi.com) - 具有 AI 增强功能的视觉化叙事软件。支持非线性、对话式演示以及动态缩放功能。
- [Curipod](https://curipod.com) - 专为教育工作者和培训师设计的 AI 驱动互动演示文稿。提供实时参与工具。

## 基于网络与协作

基于云的工具，支持实时协作、轻松共享和跨平台访问。

- [Pitch](https://pitch.com) - 为现代团队设计的协作演示软件。支持实时编辑、评论和版本控制，并与 Slack 集成。
- [Canva](https://www.canva.com) - 免费的设计工具，提供数千种演示模板。Magic Design AI 可自动生成布局。拥有超过 200 万种素材。
- [Google Slides](https://www.google.com/slides/about/) - 免费的在线演示工具，支持无缝的实时协作。与 Google Drive、Docs 和 Sheets 集成。
- [Visme](https://www.visme.co) - 拖放式编辑器，提供超过 15,000 种模板、动画和数据可视化功能。Brand Wizard 确保品牌一致性。
- [Slidebean](https://www.slidebean.com) - 为演示文稿设计的 AI 辅助工具，适用于商业提案。结合专业模板与协作编辑功能。
- [Microsoft PowerPoint Online](https://www.microsoft.com/en-us/microsoft-365/powerpoint) - 基于云的 PowerPoint，支持实时协作、Designer AI 和 Copilot 集成。
- [Zoho Show](https://www.zoho.com/show/) - 在线演示软件，支持实时协作。是 Zoho 办公套件的一部分。
- [Slides](https://slides.com) - 基于 Reveal.js 构建的网络演示编辑器。结合代码灵活性与可视化编辑界面。
- [Slidesfly](https://slidesfly.com) - 通过 CLI 或 Agent Skill 将现有 HTML、Reveal.js、Slidev 或 Marp 幻灯片发布为稳定的分享链接。
- [Swipe](https://www.swipe.to) - 以移动设备为优先的演示平台。可从任何设备创建和展示，支持触控优化的操作。
- [Emaze](https://www.emaze.com) - 基于云的演示软件，提供 3D 模板和自动设计功能。支持视频演示和分析。
- [Genially](https://genial.ly) - 创建互动演示、信息图表和游戏化内容。提供丰富的动画和互动选项。

## 开发者与基于 Markdown

适合喜欢编写代码和使用版本控制的开发者。这些工具可与 Git/GitHub 工作流集成。

- [Slidev](https://sli.dev) - 为开发者设计的演示幻灯片。支持使用 Markdown、Vue 和 HTML 编写。基于 Vue.js 和 Vite 构建。采用 MIT 许可。
- [Reveal.js](https://revealjs.com) - HTML 演示框架。使用 HTML/CSS/JS 创建互动的网络演示文稿。支持嵌套幻灯片和插件。
- [Marp](https://marp.app) - Markdown 演示生态系统。将 Markdown 转换为 HTML、PDF 和 PowerPoint。提供 VS Code 扩展。
- [Remark.js](https://remarkjs.com) - 在 Linux 和其他平台上创建 Markdown 演示文稿。简单、强大，并可通过插件高度自定义。
- [MDX Deck](https://mdx-deck.jxnblk.com) - React + Markdown 演示框架。使用 MDX 语法构建演示文稿，并完全支持 React 组件。
- [Spectacle](https://formidable.com/open-source/spectacle/) - 基于 React 的演示库。使用 JSX 和 React 组件构建演示文稿。
- [Fusuma](https://hiroppy.github.io/fusuma/) - 基于 Markdown 的演示工具，支持实时重载。支持 WebSlides 和 PDF 导出。
- [Deckset](https://www.deckset.com) - Mac 和 iOS 应用程序。用 Markdown 编写演示文稿，并提供精美主题。非常适合 Apple 生态系统用户。
- [Cleaver](https://jdan.github.io/cleaver/) - 为开发者设计的 30 秒幻灯片工具。从 Markdown 文件生成演示文稿，使用简单的 YAML 配置。
- [Hacker Slides](https://github.com/msoedov/hacker-slides) - 为开发者设计的演示工具。用 Markdown 编写，在浏览器中展示，并存储在 GitHub 上。
- [Pandoc](https://pandoc.org) - 通用文档转换器。将 Markdown 转换为多种演示格式（如 reveal.js、PowerPoint、Beamer 等）。
- [Backslide](https://github.com/sinedied/backslide) - 用于从 Markdown 创建 HTML5 演示文稿的 CLI 工具。轻量且对开发者友好。
- [Sli.do](https://www.slido.com) - 与演示文稿集成的问答和投票平台。非常适合开发者会议和技术演讲。

## 视觉与互动

注重创意、视觉吸引力和互动观众参与的工具。

- [Prezi](https://prezi.com) - 非线性、视觉化的叙事软件，具有基于缩放的导航。电影般的吸引人演示风格。
- [Ludus](https://ludus.one) - 幻灯片创作的无限创意。提供高级视觉编辑、动画、自定义布局和交互元素。
- [Haiku Deck](https://www.haikudeck.com) - 使用专业设计模板创建美观的视觉演示文稿。集成 AI 图像搜索功能。
- [Powtoon](https://www.powtoon.com) - 基于视频的演示文稿创建工具。结合幻灯片、动画和视频剪辑，打造动态内容。
- [Vyond](https://www.vyond.com) - 动画视频演示制作工具。创建专业的动画演示文稿，支持自定义角色和场景。
- [Animaker](https://www.animaker.com) - DIY 视频动画软件。通过拖放界面和 1000 多个模板创建动画演示文稿。
- [Vevox](https://www.vevox.com) - 互动演示平台，提供实时观众参与工具、投票和问答功能。
- [Pear Deck](https://www.peardeck.com) - 适用于课堂和培训环境的互动演示工具。支持实时学生反馈和参与。
- [Mentimeter](https://www.mentimeter.com) - 投票和互动演示工具。通过实时问答、投票和测验与观众互动。
- [Kahoot!](https://kahoot.com) - 游戏化的测验和互动演示平台。非常适合教育和培训演示。
- [Nearpod](https://nearpod.com) - 互动课程和演示平台。包括 VR 实地考察、3D 对象和游戏化功能。
- [AhaSlides](https://ahaslides.com) - 带有实时投票、测验和词云的互动演示软件。非常适合混合活动。
- [Poll Everywhere](https://www.polleverywhere.com) - 用于演示的实时投票和问答系统。支持 SMS 和网页投票的实时观众反馈系统。
- [Wooclap](https://www.wooclap.com) - 具有 18 种以上问题类型的互动演示平台。提供实时反馈和参与分析。

## 数据可视化与分析

专为数据驱动演示、图表和商业智能设计的工具。

- [think-cell](https://www.think-cell.com) - PowerPoint 插件。自动创建高级图表（甘特图、瀑布图、Mekko 图）。支持实时 Excel 集成。
- [Infogram](https://infogram.com) - 创建互动信息图、图表和可视化内容。提供丰富的数据可视化库和实时协作功能。
- [Datawrapper](https://www.datawrapper.de) - 轻松创建图表和地图。非常适合数据记者和分析师。支持发布可嵌入的可视化内容。
- [Flourish](https://flourish.studio) - 精美的数据可视化和互动图表。无需编码。提供用于数据讲故事的模板。
- [Tableau Public](https://public.tableau.com) - 免费的数据可视化平台。创建互动仪表板并嵌入演示中。
- [Power BI](https://powerbi.microsoft.com) - 微软的商业分析服务。创建互动报告和仪表板，用于数据驱动的演示。
- [Looker Studio](https://lookerstudio.google.com) - 谷歌的免费数据可视化工具。将数据转化为信息丰富的仪表板和报告。
- [ChartBlocks](https://www.chartblocks.com) - 简单的图表创建工具。支持从多个来源集成数据以实时更新图表。
- [RAWGraphs](https://www.rawgraphs.io) - 开源数据可视化框架。从电子表格创建自定义的基于矢量的可视化内容。
- [Plotly](https://plotly.com) - 互动图形库。使用 Python、R 或 JavaScript 创建出版质量的图表和仪表板。

## 专业与特定领域

- [Keynote](https://www.apple.com/keynote/) - 苹果的高级演示软件。仅适用于 macOS/iOS。设计优雅，动画功能强大。
- [LibreOffice Impress](https://www.libreoffice.org) - 开源演示软件（PowerPoint 的免费替代品）。支持多种格式。
- [Apache OpenOffice Impress](https://www.openoffice.org/product/impress.html) - 另一个免费的开源演示工具，支持多种格式。
- [Beamer](https://www.ctan.org/pkg/beamer) - 用于创建演示文稿的 LaTeX 文档类。非常适合包含复杂公式的学术和科学演示。
- [Pitch Deck](https://pitchdeck.com) - 专为初创公司融资演示文稿设计的工具。提供成功融资案例的模板和指导。
- [Slidedog](https://slidedog.com) - 多媒体演示工具。将 PowerPoint、PDF、视频和网页整合为一个无缝的演示。
- [mmhmm](https://www.mmhmm.app) - 用于视频演示的虚拟摄像头应用。为视频通话添加幻灯片、特效和动态布局。
- [Obsidian](https://obsidian.md) - 支持基于 Markdown 的演示插件的笔记应用。非常适合知识驱动型演示。
- [Notion](https://www.notion.so) - 集成演示功能的一体化工作空间。可从笔记和数据库中创建幻灯片。
- [Coda](https://coda.io) - 基于文档的演示工具。将文档、电子表格和演示整合到一个平台中。
- [OmniGraffle](https://www.omnigroup.com/omnigraffle/) - 可扩展用于创建演示的图表工具。非常适合技术型演示。
- [Miro](https://miro.com) - 带有演示模式的在线协作白板。非常适合工作坊和头脑风暴会议。
- [FigJam](https://www.figma.com/figjam/) - Figma 的白板工具，具有演示功能。非常适合设计团队和协作会议。

## 移动与轻量化

- [Google Slides Mobile](https://www.google.com/slides/about/) - 在移动设备上实现完整的 Google 幻灯片功能。支持离线编辑。
- [Microsoft PowerPoint Mobile](https://www.microsoft.com/en-us/microsoft-365/powerpoint) - 移动版 PowerPoint，带有 Copilot 和协作功能。
- [Canva Mobile](https://www.canva.com) - Canva 的移动应用，用于随时随地创建和编辑演示文稿。
- [Keynote iOS](https://www.apple.com/keynote/) - 适用于 iPhone 和 iPad 的全功能 Keynote，支持 Apple Pencil。

## 开源

- [Impress.js](https://impress.js.org) - 基于现代 Web 技术的演示框架。基于 HTML/CSS/JavaScript。
- [Shower](https://shwr.me) - 简单的 HTML 演示引擎。轻量且易于定制。
- [GitPitch](https://gitpitch.com) - 从 Git 仓库中的 Markdown 创建演示文稿。为演示提供版本控制。
- [PPTX.js](https://github.com/meshesha/PPTXjs) - 用于在浏览器中渲染 PowerPoint 文件的 JavaScript 库。无需服务器端依赖。
- [Big](https://github.com/tmcw/big) - 为忙碌的黑客设计的演示工具。基于简单 HTML 的幻灯片，配置最小化。
- [Bespoke.js](https://github.com/bespokejs/bespoke) - DIY 演示微框架。通过插件构建自定义演示体验。
- [WebSlides](https://webslides.tv) - 创建美观的 HTML 演示文稿。提供 120 多个可用的幻灯片，标记最小化。
- [Sent](https://tools.suckless.org/sent/) - 为 X11 设计的极简演示工具。轻量且符合 Unix 哲学。
- [Landslide](https://github.com/adamzap/landslide) - 从 Markdown、ReST 或 Textile 生成 HTML5 幻灯片。基于 Python，带有主题支持。
- [Hovercraft](https://github.com/regebro/hovercraft) - 从 reStructuredText 创建 impress.js 演示文稿。基于 Python，支持 3D 效果。
- [Patat](https://github.com/jaspervdj/patat) - 基于终端的演示工具。直接在终端中展示 Markdown 幻灯片。

## 插件与扩展

通过附加功能增强现有工具。

- [Microsoft Copilot Pro for PowerPoint](https://www.microsoft.com/en-us/microsoft-365/business/microsoft-copilot-pro) - 在 PowerPoint 中直接提供 AI 协助。设计建议和内容生成。
- [Google Gemini in Slides](https://workspace.google.com) - 在 Google Slides 中提供 AI 驱动的内容建议和设计协助。
- [Marp VS Code Extension](https://marketplace.visualstudio.com/items?itemName=marp-team.marp-vscode) - 在 VS Code 中直接编辑 Marp 演示文稿并实时预览。
- [Reveal.js Plugins](https://revealjs.com/plugins/) - 适用于 Reveal.js 演示文稿的广泛插件生态系统。
